## Contributing

1. Create an **issue**. Assign yourself
2. Create a **new branch** from `dev` branch. Every branch name should start from task type (`feature`, `fix` or `test`), task number and short description. e.g. **feature/125/create-navbar** 
3. Commit changes
4. Create **pull request**
5. Link pull request to an issue
6. **Squash and merge** into `dev` branch 
7. **Delete** task branch (e.g. **feature/125/create-navbar**)


## How to run

```bash
cd docker
```
```bash
docker-compose up -d
```
Then open [localhost:3080](http://localhost:3080) with your browser
(localhost:8000)
